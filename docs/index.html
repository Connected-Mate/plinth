Prompt d'installation

Plinth est une app sur mon iPhone : tu peux m'y construire de petites apps, des listes et des notes via notre Wi‑Fi (serveur MCP). Je ne suis pas technique : parle-moi avec des mots simples, sur mon téléphone.
Guide complet : https://github.com/Connected-Mate/plinth/blob/main/AGENT-SETUP.md
1. Trouve mon téléphone : sur un Mac, lance dns-sd -B _plinth._tcp local. puis dns-sd -L Plinth _plinth._tcp local. (ou demande-moi de toucher le bouton rond dans Plinth et de te coller ce qu'il copie).
2. Connecte-toi : claude mcp add --transport http plinth http://<ip-du-téléphone>:<port>/mcp (autres agents : ajoute-le comme serveur MCP HTTP). Si ses outils n'apparaissent pas, demande-moi de te redémarrer.
3. Appelle request_pairing, demande-moi le code à 6 chiffres affiché sur mon téléphone, puis appelle pair avec ce code, agent_kind et agent_name (qui tu es). Lance la commande exacte que pair renvoie, pour rester appairé la prochaine fois.
4. Lis la ressource plinth://skill (ou appelle read_guide) et suis THE METHOD : comprends ce qui me ferait plaisir, pose-moi au plus 3 questions courtes sur mon téléphone (ask_user), couvre tous les cas, construis, prouve que ça marche (screenshot_space), puis dis-moi sur le téléphone (tell_user) comment m'en servir.
Plinth ne répond que quand l'app est ouverte sur mon téléphone.

Questions

C'est gratuit ?

Oui. Pas de pub, pas d'abonnement, pas de compte à créer.

Quel agent faut-il ?

Un agent de code qui sait se brancher à un serveur MCP : Claude Code d'abord, mais aussi Codex, Cursor, Gemini CLI et les autres. Le prompt lui explique tout.

Mes données partent où ?

Nulle part. Tout circule entre ton ordinateur et ton iPhone, sur ton Wi‑Fi, et reste rangé sur ton iPhone. Aucun serveur, aucune statistique.

Mon agent ne trouve plus Plinth.

Plinth ne répond que quand l'app est ouverte sur ton iPhone, sur le même Wi‑Fi que ton ordinateur. Ouvre-la, et c'est reparti.

Le code est public ?

Pas pour l'instant. Ce dépôt contient le site ; le code de l'app n'est pas encore publié.
