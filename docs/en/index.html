Setup prompt

Plinth is an app on my iPhone: you can build me small apps, lists and notes on it over our Wi‑Fi (MCP server). I'm not technical: talk to me in plain words, on my phone.
Full guide: https://github.com/Connected-Mate/plinth/blob/main/AGENT-SETUP.md
1. Find my phone: on a Mac run dns-sd -B _plinth._tcp local. then dns-sd -L Plinth _plinth._tcp local. (or ask me to tap the round button in Plinth and paste you what it copies).
2. Connect: claude mcp add --transport http plinth http://<phone-ip>:<port>/mcp (other agents: add it as an HTTP MCP server). If its tools don't show up, ask me to restart you.
3. Call request_pairing, ask me for the 6-digit code shown on my phone, then pair with it plus agent_kind and agent_name (who you are). Run the exact command pair returns, so you stay paired next time.
4. Read the resource plinth://skill (or call read_guide) and follow THE METHOD: understand what would make me happy, ask me at most 3 short questions on my phone (ask_user), cover every scenario, build it, prove it works (screenshot_space), then tell me on the phone (tell_user) how to use it.
Plinth only answers while the app is open on my phone.

Questions

Is it free?

Yes. No ads, no subscription, no account to create.

Which agent do I need?

A coding agent that can connect to an MCP server: Claude Code first, but also Codex, Cursor, Gemini CLI and the rest. The prompt tells it everything.

Where does my data go?

Nowhere. Everything travels between your computer and your iPhone over your Wi‑Fi, and stays on your iPhone. No server, no analytics.

My agent can't find Plinth anymore.

Plinth only answers while the app is open on your iPhone, on the same Wi‑Fi as your computer. Open it and you're back.

Is the code public?

Not for now. This repository holds the website; the app's code isn't published yet.
